# Nexora Project Manager

Starter folder structure for the Nexora collaborative project management hackathon.

## Stack
- Frontend: React + Vite + JavaScript + Tailwind CSS
- Backend: Node.js + Express
- Database: Local PostgreSQL

## Structure
- `frontend/`: React UI
- `backend/`: Express API, authorization, and PostgreSQL setup

## Next steps
1. Install frontend dependencies in `frontend/`.
2. Install backend dependencies in `backend/`.
3. Configure `backend/.env` using `.env.example`.
4. Create the PostgreSQL database and run `backend/database/schema.sql`.
5. Implement features in this order: login, projects, tasks, role permissions, comments.

This is a scaffold containing folders and placeholder files, not a fully implemented application.
